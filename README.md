# MANG_01 — CEO Cockpit Design

مخزن طراحی سامانه CEO Cockpit برای پایش مدیریتی و کیفیت داده در محیط خودمیزبان.

## سند اصلی
- [سند جامع طراحی سیستم (فارسی)](docs/SYSTEM_DESIGN.md)
- [سند حاکمیت داده: تنظیمات، داده‌های ورودی، تحلیل‌ها و ماتریس ورود دستی](docs/INPUT_DATA_GOVERNANCE.md)

## اصل اجرایی
سامانه باید تنظیمات سیستم (SETTING)، داده‌های ورودی (INPUT) و داده‌های تحلیلی (ANALYTICAL) را در مدل داده، API و UI از هم تفکیک کند. بخش ورود داده‌های پایه و مستر دیتا یک قابلیت اصلی محصول است و باید ماتریس مسئولیت/فرکانس ورود دستی را پشتیبانی کند.

هیچ KPI، مقدار، آستانه، نقش، اتصال یا رفتار تأییدنشده‌ای را حدس نزنید. موارد باز باید «نیازمند تأیید» بمانند. داده نمایشی باید DEMO باشد و به‌عنوان داده واقعی عرضه نشود.

## وضعیت
این مخزن در حال حاضر مستندات طراحی را دریافت می‌کند؛ وجود سند طراحی به معنی پیاده‌سازی یا آمادگی عملیاتی برنامه نیست.
